DAKSH TYAGI PORTFOLIO
======================

Files:
- index.html: page content
- style.css: responsive dark premium styling and animations
- script.js: mobile navigation and contact form email handoff

Run locally:
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code + Live Server.

Before publishing:
1. Replace daksh.tyagi@example.com with your real email in index.html and script.js.
2. Replace generic GitHub/LinkedIn links with your profiles.
3. Add your real resume PDF as resume.pdf in this folder.
4. Replace placeholder profile initials with your own photo if desired.
5. Replace generic repository links with each project's real GitHub and live demo URL.

The contact form opens the visitor's email application; it does not submit to a server.
